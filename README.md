## Featured Projects

### 1. 555 Timer-Based Buck Converter with KiCad PCB

<a href="https://github.com/devikanambiar05/buck_converter_pcb">
<img src="https://github-readme-stats.vercel.app/api/pin/?username=devikanambiar05&amp;repo=buck_converter_pcb&amp;bg_color=0A192F&amp;title_color=00B4FF&amp;text_color=CCD6F6&amp;icon_color=00B4FF&amp;border_color=112240" alt="Buck Converter PCB repository" />
</a>

**Objective:** Design a DC-DC buck converter to step down a 12V input to approximately 5V.

| Parameter | Details |
|---|---|
| Design | 555 timer-based PWM control |
| Controller | NE555 |
| MOSFET | IRF740 |
| Diode | Schottky freewheel diode |
| Inductor | 220 µH |
| Output capacitor | 220 µF |
| Load | 10 Ω |
| PCB | Two-layer PCB |
| Tools | KiCad |

**Current progress:**
- Designed the circuit and PCB layout.
- Generated Gerber files.
- Measured the 555 timer oscillator at 17.45 kHz and approximately 50% duty cycle.
- Power-stage testing is in progress.

[View Repository →](https://github.com/devikanambiar05/buck_converter_pcb)
