## 🚀 Featured Projects

### 1. 555 Timer-Based Buck Converter with KiCad PCB

[![buck_converter_pcb](https://github-readme-stats.vercel.app/api/pin/?username=devikanambiar05&repo=buck_converter_pcb&bg_color=0A192F&title_color=00B4FF&text_color=CCD6F6&icon_color=00B4FF&border_color=112240)](https://github.com/devikanambiar05/buck_converter_pcb)

| | |
|---|---|
| **Objective** | Step 12 V down to about 5 V, with the 555 timer driving a low-side N-channel MOSFET directly so no gate driver is needed |
| **Design** | Duty ratio and load current worked out from first principles (D ≈ 0.42, 10 Ω load); IRF740 MOSFET, Schottky freewheel diode, 220 µH inductor, 220 µF output filter |
| **Tools** | KiCad, NE555 |
| **PCB** | Two-layer, through-hole, Gerbers included |
| **Status** | PCB designed. 555 oscillator measured on the bench (17.45 kHz, 50% duty) and the gap from the calculated value traced to component tolerance. Power-stage testing is in progress |

**Repository:** [buck_converter_pcb](https://github.com/devikanambiar05/buck_converter_pcb)
